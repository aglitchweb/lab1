###### Назначение файлов

* ###### `inventory.py` — собирает сведения об ОС, процессоре, оперативной памяти, дисках и сетевых интерфейсах; формирует рекомендации и сохраняет технический паспорт в JSON.
* ###### `monitor.py` — выполняет мониторинг CPU, RAM и диска, записывает результаты в CSV, проверяет пороги и выводит статистику.
* ###### `passport\\\_<имя\\\_компьютера>.json` — создаётся автоматически после запуска `inventory.py`.
* ###### `monitor\\\_log.csv` — создаётся автоматически после запуска `monitor.py`.

###### Параметры варианта 6

* ###### Интервал между измерениями: 5 секунд.
* ###### Количество измерений: 12.
* ###### Пороги: CPU — 70%, RAM — 70%, DISK — 90%.
* ###### Дополнительные показатели: доступная RAM в ГБ и максимальная загрузка одного логического процессора в процентах.

###### Установка и запуск в Windows

###### Откройте терминал в этой папке и выполните:

```bat
py -m venv venv
venv\\\\Scripts\\\\activate
python -m pip install psutil
python inventory.py
python monitor.py
```
---

###### Для повторного запуска достаточно активировать окружение и выполнить нужный скрипт:

```bat
venv\\\\Scripts\\\\activate
python inventory.py
python monitor.py
```
